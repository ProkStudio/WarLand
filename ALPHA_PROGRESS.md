# WarLand — журнал запуска игровой альфы

Обновлено: 2026-09-06, продолжение после 16:00 МСК.

## Цель
Довести ограниченную альфу до доступного сервера и выдать клиентский комплект. Пользователь разрешил автономную разработку и замену старого сервера. Сначала сохраняем резервные копии. Фоновое продолжение после закрытия диалога не гарантируется.

## Проверенное состояние
- GitHub ProkStudio/WarLand доступен с правами записи. main пока содержит документацию.
- Кандидат: `release/0.1.0-alpha.2`, исходники `2a89fa966f0f3fabf90d785fc22aaebb52655db1`. Включает opt-in encrypted-offline, постоянный ключ, pre-shared pin и защиту позднего повторного LOGIN плюс CONFIGURATION reservation.
- Сервер доступен. Paper занимает публичный порт 25565; старый Fabric staging — loopback 25566. Ни один не удалён.
- Отдельный checkout: `/opt/warland-build/solo-alpha-20260906`, локальная ветка `release/alpha-launch-20260906`. Старые dirty checkout не тронуты.
- Запущены Java clean test build (версия 0.1.0-alpha.2) и Python tests под build-user и OS flock. Итог пока НЕ прочитан. Результаты `/opt/warland-build/solo-alpha-{java,python}.log`, `solo-alpha-build.exit`.
- Локальный sandbox не может разрешить github.com; сборка выполняется на подключённом VPS с проверенным cached Gradle.

## Следующие шаги
1. Прочитать результат сборки и исправить реальные ошибки, если есть.
2. Новый изолированный native encrypted-offline runtime: register→PLAY, неправильный пароль, restart→login, стабильный ключ и отсутствие повторной выдачи денег. Проверить повторное подключение.
3. Сохранить старый Paper, подготовить независимый alpha-runtime и безопасную локальную консоль; никаких тестовых authlib overrides.
4. Подготовить клиентский JAR + Fabric API + публичный server pin и инструкцию установки.
5. Переключить публичный порт только после успешного smoke, проверить ответ извне и сохранить точные хеши/ограничения.

## Границы
Не включать непроверенные финансовые операции/escrow/захваты. Не назначать owner/OP по одному нику. Ключи, пароли, bootstrap, миры и базы не публиковать. Native Minecraft RSA/AES-CFB8 с pin — не TLS/AEAD. Реальная GUI-приёмка и многопользовательская нагрузка пока не подтверждены. Ограниченная альфа не равна завершённому полному ТЗ.
