# Как зайти в WarLand 0.1.0-alpha.2

Это ограниченная игровая альфа, не завершённое полное ТЗ. Сервер: **201.51.10.116:25565**. Java Edition, **Minecraft 1.21.11**, Java 21, **Fabric Loader 0.19.5**. Bedrock и чистый vanilla-клиент не поддерживаются.

## Установка
1. Скачайте `WarLand-0.1.0-alpha.2-client.zip` из [GitHub Releases](https://github.com/ProkStudio/WarLand/releases/tag/v0.1.0-alpha.2). Не путайте с автоматически создаваемым Source code.zip.
2. Создайте отдельный профиль/экземпляр Minecraft 1.21.11 с Fabric Loader 0.19.5. Официальный установщик: https://fabricmc.net/use/installer/ . Не используйте папку другой сборки; старые моды WarLand удалите только из нового профиля, если скопировали их туда.
3. Распакуйте содержимое клиентского ZIP в игровую папку этого профиля. В ней должны оказаться `mods/warland-0.1.0-alpha.2.jar`, `mods/fabric-api-0.141.6+1.21.11.jar` и `config/warland/server-fingerprint.txt`.
4. Выделите клиенту 2–3 ГБ RAM, запустите Fabric-профиль. Добавьте сервер `201.51.10.116:25565`.
5. В появившемся окне WarLand введите собственный уникальный пароль (12–128 символов), повторите его и нажмите «Регистрация». Поле кода владельца обычным игрокам оставлять пустым. В дальнейшем используйте тот же ник, пароль и кнопку «Войти».

Пароль не вводится в чат, не сохраняется в клиентском комплекте и не должен совпадать с паролем почты/Microsoft. Используйте менеджер паролей. Для зарезервированного имени владельца нужен отдельный приватный одноразовый код; публичный ZIP его не содержит. OP по одному никнейму не выдаётся.

## Первые действия
- `/warland` — главное меню.
- `/warland tutorial` — обучение.
- `/balance` — баланс, стартовая выдача один раз.
- `/quests` — задания.

## Безопасность и ограничения
- Комплект содержит публичный отпечаток именно этого сервера. При сообщении «ключ сервера не подтверждён» проверьте путь config и скачайте актуальный комплект из этого репозитория. **Не отключайте проверку ключа.**
- Идентичность аккаунта подтверждается паролем WarLand, не Mojang UUID. Смена ника означает другой аккаунт. Старые Paper-миры/аккаунты не перенесены; для альфы создан отдельный мир.
- Используется native Minecraft RSA/AES-CFB8 с заранее закреплённым ключом, не TLS/AEAD.
- Лимит сервера — 10 игроков. Это ограничение ресурса, не подтверждение нагрузочной приёмки на 10 человек.
- Скупщик, аукцион/escrow, покупки зданий и захваты намеренно не включены до игровой/crash-приёмки. Авиация, финальный HUD, полный баланс и бета 10/20/30 не завершены.
- Первичный GUI/протокольный smoke не заменяет длительный совместный playtest. Текущий фактический статус и адрес: [ALPHA_PROGRESS](https://github.com/ProkStudio/WarLand/blob/main/ALPHA_PROGRESS.md).
