# Интеграция ядра и хаба

Реализованные защиты (проверка полного клиента учитывается отдельно в VERIFICATION.md):

- Всё служебное измерение `warland:capital` защищено до и после регистрации точки появления. Это изолированный хаб, не третий ресурсный мир.
- Read-only терминалы контентного модуля используют отдельную Fabric-фазу раньше общего запрета использования блоков. Обычное использование блоков в хабе не разрешается.
- `WarLandApi.canBuildCity` по умолчанию запрещает размещение. Ядро требует свой приват, членство и право строительства, дополнительно применяет обычные защиты. Интегратор обязан переключить проверки BuildingService на этот метод; покупки остаются закрыты до приёмки.
- Частный `capital-<nation>` проверяет текущую принадлежность игрока и чанка, а не только отображение GUI. Права и неизменность цели повторно проверяются после задержки телепортации.
- Новый профиль получает долговечный маркер ожидания хаба. Прибытие выполняется только после регистрации проверенного spawn, вне боя/техники/инвентарной операции. Возвращающиеся профили без этого маркера не перемещаются. Позиция Minecraft и SQLite не объявляются единой атомарной транзакцией.
- `/warp survival` выбирает безопасную сухую поверхность рядом с обычной точкой появления, без изменения блоков и без попадания в существующий приват. Проверяется по одному кандидату в секунду, максимум 81. Небольшая зона прибытия защищена. Поиск повторяется при запуске; если все кандидаты непригодны, требуется настройка транспорта, а не разрушение мира.
- Опциональный `InventoryGuard.busy(UUID)` блокирует чувствительные действия ядра и открытие другого меню. Отсутствующий market-модуль допустим; сломанный установленный guard блокирует действия. Это НЕ полная инвентарная защита: packet/drop/pickup/container/death/recovery hooks и их испытания принадлежат market-модулю.
- Взрывы получают изменяемый список блоков, допустимый для vanilla; размещение кровати проверяет оба чанка.

Ни один из этих пунктов не включает автоматически закрытые покупку зданий, AH, скупщик или захват территории. Не выполненная приёмка не считается пройденной.
