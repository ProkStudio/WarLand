# Проверки WarLand — факты, а не план

## Первый проверенный срез ядра (05.09.2026 UTC)

- Gradle 9.2.1 + Loom 1.14.10: `build` успешен.
- Компиляция с Java release 21, Minecraft 1.21.11, Yarn 1.21.11+build.6.
- 13 исходных unit/integration-тестов: RulesTest — 6; StoreTest — 7. Ошибок и пропусков нет. Последующие дополнительные тесты ядра учитываются в docs/CORE_QA.md после их завершения.
- Реально запущен dedicated Fabric 0.19.5 с WarLand jar и Fabric API 0.141.6+1.21.11. Это отдельный непривилегированный процесс, loopback-порт, копия мира. Рабочий Paper не заменялся.
- Сервер дошёл до `Done` и `WarLand ready`; обязательные mixin загрузились без ошибки.
- SQLite `quick_check` = `ok`, schema version = 1.
- Консольные `warland status`, `wladmin diag`, `list` выполняются.

## Реальный сетевой тест (не вызов сервиса в обход Minecraft)

Локальный диагностический клиент протокола 774 прошёл login/configuration/play, отвечал на keepalive и teleport confirmation, отправлял игровые команды и клики контейнерных меню.

1. Новый синтетический игрок получил 1500 кредитов.
2. Открыл все пять страниц обучения и нажал «Далее»/«Завершить» сетевыми кликами меню.
3. Через подтверждение создал тестовое государство за 1000; автоматически появился один столичный приват.
4. Через подтверждение внёс 200 в казну.
5. Проверка реальной SQLite: баланс игрока 300, казна 200, обучение завершено, один чанк, одна стартовая выдача.
6. Повторный вход того же игрока показал баланс 300: повторной стартовой выдачи нет.
7. Открылись меню государства и войны; команда территории показала владельца.
8. Сервер штатно сохранил мир и остановился.

Все тестовые игроки и государства созданы только в изолированной копии. Это не перенос данных пользователей и не готовый сезон.

## Что эта проверка НЕ доказывает

- Это не тест 30 игроков и не доказательство TPS под войной/авиацией.
- Диагностический клиент не рендерит графику; визуальная проверка моделей этим не выполнена.
- Скупщик, AH, техника, строительство, ивенты и инвентарные crash-сценарии первого среза здесь не считаются проверенными.
- Полный rollback контейнеров/инвентарей, античит, балансовая экономика и сезоны ещё требуют отдельной приёмки.
- Стабильность после реального kill -9 и корректность всех механизмов на границах приватов этим не подтверждены.

Опасные игровые функции не открываются публично только на основании зелёной компиляции. Итоги интеграции дополнительных модулей добавляются отдельным разделом с фактическими результатами.
