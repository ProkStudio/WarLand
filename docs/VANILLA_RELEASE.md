# WarLand 0.1.0-alpha.3

Ограниченная предварительная версия для **обычного Minecraft Java 1.21.11**. Полное ТЗ и stable-релиз ещё не завершены.

## Игрокам

1. Запустите обычный Minecraft Java **1.21.11**. Fabric, WarLand-мод и специальный лаунчер больше не нужны.
2. Адрес публичной альфы: `201.51.10.116:25565`. Текущее состояние развёртывания — в [PLAY_ALPHA.md](https://github.com/ProkStudio/WarLand/blob/main/PLAY_ALPHA.md).
3. При первом входе задайте отдельный пароль и повторите его, нажмите «Регистрация». В дальнейшем достаточно пароля и «Войти».
4. Примите обычный запрос обязательного серверного ресурспака. Minecraft скачает, проверит и закэширует его самостоятельно; ставить файлы вручную не нужно.
5. `/warland` — главное меню, `/balance` — баланс, `/warland tutorial` — обучение.

**Пароль виден при вводе.** Не используйте пароль от почты/Microsoft/других серверов и не показывайте ввод посторонним. Native RSA/AES-CFB8 — не TLS/AEAD; обычный клиент не закрепляет заранее известный ключ сервера. Зарезервированный ник владельца требует приватного подтверждения, не выдаёт OP по одному имени.

## Операторам

`warland-server-0.1.0-alpha.3.zip` содержит небольшой Python-установщик, точный manifest и русскую инструкцию. Нужны Linux x86-64, Python3.12+ и HTTPS.

После ознакомления и согласия с Minecraft EULA:

```sh
python3 bootstrap_server.py --directory WarLand-server --accept-eula
./WarLand-server/start.sh
```

Установщик автоматически получает WarLand, Fabric launcher, Fabric API, Polymer и ресурс-пак по SHA-256; если Java21 нет, получает проверенный Temurin JRE. Fabric при первом старте получает Minecraft и свои библиотеки. Отдельно устанавливать моды игрокам не нужно.

Установка только в новый каталог или продолжение СВОЕЙ прерванной установки с тем же manifest. Чужие/существующие серверы и настройки не перезаписываются. Все релизные файлы перечислены в `SHA256SUMS`. [Процедура обновления и отката](https://github.com/ProkStudio/WarLand/blob/v0.1.0-alpha.3/docs/VANILLA_DEPLOY.md).

## Проверки и границы

- CI перед публикацией делает clean build и полные Java/Python suites, проверяет комплект и контрольные суммы.
- Отдельный native wire QA подтвердил отмену, отклонение stale/unknown действий, регистрацию, обязательный pack, PLAY/balance, graceful restart, неверный пароль, повторный вход и отсутствие повторной стартовой выплаты.
- Официальный клиент без Fabric прошёл регистрацию, штатное согласие, реальное скачивание/перезагрузку ресурспака, PLAY, inventory/model и balance. Визуально проверены форма и игровая модель АК-74/магазина. Это не визуальная аттестация всех экранов.
- Проверен реальный download/extract/version probe закреплённого Temurin JRE и повторное использование установленной Java. Отсутствие системной Java при этом моделировалось только в поиске исполняемого файла.
- Изолированный GUI проходил на VPS с software rendering, не является внешней пользовательской beta и нагрузочным тестом. GUI повторный вход не завершён; повторный вход/ошибка пароля проверены отдельным native wire сценарием.
- Рынок, покупки зданий и захват остаются отключены. Полные crash-safety/recovery, moderation, авиация/final HUD и beta10/20/30 остаются отдельными stable-гейтами. Оружие пока использует общую прототипную модель.

Polymer 0.15.2+1.21.11: Patbox/contributors, LGPL-3.0-only, https://github.com/Patbox/polymer. Зависимости скачиваются из источников разработчиков без изменений. Java: Temurin/OpenJDK, GPL-2.0 with Classpath Exception; точный выпуск/источник в manifest. Minecraft/Java binaries и runtime-данные игроков в установщик не включены.
