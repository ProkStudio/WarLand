# WarLand 0.1.0-alpha.3.3 — команды владельца в чате

Это **prerelease / серверный патч**, не полный stable и не новый installer. Minecraft Java 1.21.11, обычный клиент без модов, прежний ресурспак. Аккаунты, ключ, роли, миры и настройки не сбрасываются.

## Использование
- `/wladmin` или `/wladmin help` — первая страница справки в чате вместо прежнего двухкнопочного меню.
- `/wladmin help 2` … `/wladmin help 7` — остальные страницы (число страниц зависит от подключённых команд и прав).
- До 4 описаний / 11 сообщений на страницу. Каждое описание содержит синтаксис, назначение, ограничения и пример.
- 27 записей: диагностика, жалобы и их закрытие, роли/наказания персонала, управление размещением столицы, опасные строительные переключатели и восстановление, тестовое оружие/техника, календарь сезонов.
- Существующие `/wladmin diag`, `reports`, `resolve` сохранены; `/staff` остаётся совместимым. Обычные игровые команды — `/help`.
- Примеры — **только текст**, не кнопки выполнения. `TestPlayer`, `<UUID>`, `<job-id>`, `<будущая-дата>` заменить проверенными значениями, а не копировать вслепую.

## Безопасность и границы
Справку получает только текущий авторизованный владелец или допустимая приватная консоль. Ник/OP не подменяют роль OWNER. Существующий корневой guard сохранён; новый обработчик повторно проверяет авторизацию даже для разобранной ранее команды. Отсутствующие и недоступные ветви не показываются. Справка не читает секреты, не исполняет команды, не меняет данные или права.

Наличие команды не означает готовность функции. `/citybuild purchases` прямо обозначен как опасный эксперимент с неатомарным escrow; пример оставляет `false`. Техника/выдача оружия остаются тестовыми прототипами. Этот патч не включает новые gameplay-флаги и не завершает market/авиацию/crash-safety.

Безопасный `/rtp` из alpha.3.2 сохранён. При медленной генерации возможен ограниченный отказ — повторять не раньше 30 секунд; успешный перенос сохраняет cooldown 180 секунд.

## Установка / откат
Это патч поверх существующей Fabric1.21.11 среды, не самодостаточный installer. Для штатного VPS используется service-bound процедура: отсутствие игроков, graceful stop, приватный полный backup с проверкой чтения, один новый WarLand JAR вmods, запуск и сверка версии/ключа/данных. Никогда не оставлять две версии одновременно.

При ошибке вернуть только предыдущий JAR, сохранив актуальные базы и миры. Не восстанавливать старую БД поверх новых действий игроков. Не использовать bootstrap для уже привязанного владельца.

## Ещё не готово
Авторизация через чат в изолированном лобби, lobby на каждый вход, оформление крепости160×160, TAB[OWNER]/sidebar с деньгами, реальная графическая и beta/load-приёмка, полный stable#15 — отдельные задачи. Не выдавать этот патч за их завершение.
