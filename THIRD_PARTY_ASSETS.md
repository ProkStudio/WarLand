# Реестр сторонних компонентов и ассетов

## Игровые ассеты

Сторонние модели техники, текстуры из других игр и платные наборы не включались. Оригинальные модели и шаблоны строятся для WarLand; ссылки на встроенные текстуры Minecraft используют установленный клиент, а не публикуют оригинальные файлы игры. Фактический состав модуля техники см. docs/COMBAT.md после интеграции.

## Технические зависимости

- Fabric Loader 0.19.5 — https://github.com/FabricMC/fabric-loader, Apache-2.0.
- Fabric API 0.141.6+1.21.11 — https://github.com/FabricMC/fabric, Apache-2.0; отдельный мод-зависимость.
- Xerial SQLite JDBC 3.49.1.0 — https://github.com/xerial/sqlite-jdbc, Apache-2.0; лицензии внутри оригинального вложенного jar сохраняются. SQLite — public domain.
- Yarn mappings и Fabric Loom — инструменты сборки, не игровые модели. Условия проверять в их репозиториях при распространении производных артефактов.
- Minecraft распространяется владельцем игры, не этим репозиторием. EULA и правила использования Minecraft продолжают действовать.

## Добавление новых ассетов

Для каждого нового ассета необходимы точный URL, commit/tag, автор, отдельная лицензия на модель/текстуру, разрешение на производные работы и распространение, изменения и атрибуция. Публичность репозитория без LICENSE не даёт права копировать. Реальные названия техники не означают одобрение правообладателями. Собственная публичная лицензия проекта ещё не выбрана; не считать отсутствие лицензии разрешением на переиспользование.
